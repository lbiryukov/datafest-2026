# DataFest Tbilisi 2026: программа и мой план

Страница с программой фестиваля (26–28/11/2026, Pullman Tbilisi Axis Towers) и личным планом посещения.

- `index.html`, `app.js` — сама страница, публикуется через GitHub Pages: https://lbiryukov.github.io/datafest-2026/
- `data/agenda.json` — 90 сессий с официального сайта (https://www.datafest.ge/agenda/, состояние на 25/11/2026), русские пересказы и рекомендации Claude (`rec`, `why`, `route`).
- `data/plan.json` — выбранные сессии (`picks` — id из `agenda.json`). Страница сама коммитит сюда изменения.

## Как работает сохранение

Страница читает `data/plan.json` через GitHub API и при каждом изменении (с задержкой ~1 с) записывает его обратно коммитом. Для записи нужен fine-grained токен с доступом только к этому репозиторию и правом Contents: Read and write; он вводится на странице и хранится только в localStorage браузера. Без токена план читается из репозитория, а правки остаются в браузере до ввода токена.

Токен в репозиторий не попадает никогда.
